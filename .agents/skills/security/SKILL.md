# Security Workflow

Identify externally controlled content, data collection, redirects, and browser-visible values.
Never put credentials or private keys in static files, React source, or `VITE_*` values. Preserve
HTTPS checkout links and safe external-link behavior. Treat payment, privacy, and deployment
changes as Tier 3 unless evidence makes the risk lower.
