# Feature Workflow

Confirm which artifact is affected: production `index.html`, React/Vite source, or both. Define
visible behavior and acceptance criteria, locate one equivalent section, then make the smallest
compatible change. Preserve performance, accessibility, responsive layout, real assets, and CTA
links. Build React source when changed and report any required artifact synchronization.
